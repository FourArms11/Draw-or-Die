# Week 3 - Real-Time Multiplayer

**Milestone dates:** 2026-09-17 to 2026-11-17

### Progress

- Connected the game to Socket.IO rooms, live player lists, host controls, and room state updates.
- Added server-managed turns, timers, word selection, scoring, chat, and drawing synchronization.
- Added authentication support for sockets, disconnect handling, and end-to-end multiplayer tests.

### Outcome

The local prototype became an online multiplayer game. The server became the authority for room membership, game state, and scores.
